# 专升本每日学习总结（增强版）

纯前端专升本备考记录工具：学习记录 + 番茄钟 + 游戏化激励 + 数据可视化。

## 技术栈

- Vue 3 (Composition API) + Vite + TypeScript
- Tailwind CSS（移动端优先响应式）
- Pinia 状态管理 + localStorage 持久化
- ECharts 数据可视化 / KaTeX 公式渲染

## 功能

- **首页仪表盘**：今日概览、待办排序、学习热力图、进度环、考试倒计时、每日名言
- **高等数学**：考纲章节树、学习计时、刷题记录、掌握度雷达、Markdown+LaTeX 笔记、真题趋势
- **英语**：词汇打卡、阅读计时、听力记录、作文模板库、笔记检索
- **扩展科目**：动态添加，统一面板零成本接入
- **错题本**：图片上传（Base64）、分类、复习计数
- **番茄钟**：正/倒计时、白噪音（WebAudio 生成）、中断记录、全屏沉浸
- **游戏化**：积分、等级（青铜→王者）、成就徽章墙、连胜计数
- **每日总结**：自动聚合数据、情绪日志、三段式反思、分享卡片、日历回顾
- **统计中心**：时长/占比/正确率/题型/专注/情绪多维图表、周报
- **习惯追踪**：四种量化方式、30 天热力、坏习惯监督
- **资料库**：书籍进度条、链接、笔记摘抄
- **设置**：目标、考试日期、深浅色主题、JSON 导入导出、存储用量

## 开发

```bash
npm install
npm run dev
```

## 构建部署

```bash
npm run build
```

产物在 `dist/`，为纯静态文件，可直接部署到 GitHub Pages / Vercel。
（路由使用 hash 模式，无需服务端 rewrite 配置。）

## 数据说明

所有数据保存在浏览器 localStorage（键：`zsb-study-tracker-v1`），可在「设置 → 数据管理」导出 JSON 备份。
